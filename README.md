# Просветление — демонстрация нового дизайна

Статическая демонстрационная версия. Для просмотра не нужен сервер приложений или база данных. Включены HTML, CSS, JavaScript и изображения.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий в своём GitHub.
2. Распакуйте архив и загрузите его содержимое в корень репозитория: index.html должен находиться на верхнем уровне, рядом со styles.css и папкой assets. Загружайте распакованные файлы, не сам ZIP.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку с загруженными файлами (обычно main) и папку /(root), затем Save.
6. Дождитесь публикации. Ссылка появится в разделе Pages.

В бесплатном аккаунте GitHub Pages доступен для публичных репозиториев.

## Содержание

Сохранены исходные текстовые блоки главной, новости, фотографии галереи, контакты и ссылки на действующие разделы yogacenter.ru. Внутренние страницы, расписание и магазин открываются на действующем сайте. Телефонные ссылки и email открывают соответствующие приложения; новая обработка заказов и платежей не создавалась.

Демонстрация не является действующим сайтом центра. В дизайне также используются демонстрационные фотографии Unsplash.
